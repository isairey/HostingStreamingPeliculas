# 🌌 Acerca del proyecto

**YourMovies** es una plantilla web moderna enfocada en la creación de plataformas multimedia para streaming y hosting de películas.

El sistema fue diseñado para ofrecer:

- 🎬 Streaming multimedia
- 📱 Diseño responsive
- ⚙️ Panel administrativo moderno
- 🌐 Hosting de películas
- 🎨 UI cinematográfica
- ⚡ Navegación rápida

La plantilla permite crear fácilmente un sitio web tipo Netflix o plataforma OTT personalizada.

# ⚡ Instalación

## 1️⃣ Descargar archivos

Clonar o descargar el proyecto desde GitHub.

```bash
git clone https://github.com/your-user/yourmovies.git
```

---

## 2️⃣ Mover archivos al servidor

Colocar los archivos en:

- Local Server
- Hosting Server
- Apache / XAMPP / Laragon

---

## 3️⃣ Ejecutar instalador

Abrir en navegador:
